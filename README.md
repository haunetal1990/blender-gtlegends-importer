# Blender GT Legends Importer

This plugin allows the direct import files from the classic game **GT Legends** into Blender. It imports not only the 3D models but also their corresponding materials.

- Files: `.CAR`, `.CAS`, `.TRK`, `.SCN`, `.GTL`, `.GMT`
- Blender 4.0+ (add-on) and 4.2+ (extension)
- Menu: File > Import > GT Legends (.GTL)

You need your own copy of GT Legends. No game files are included.
